RELAY GATEWAY · v0.2.0

A multi-tenant, OpenAI-compatible LLM gateway.

Virtual-key auth, per-app routing & failover, rate limits & budgets, exact-response cache, priced usage metering, and a hash-chained audit trail — every tenant isolated by Postgres row-level security. Point the OpenAI SDK at it and it just works. 

# from source
git clone https://github.com/chetan-01-source/relay && cd relay
make bootstrap && make dev

curl -N http://localhost:3000/v1/chat/completions \
  -H "authorization: Bearer $(cat .relay/seed-demo.key)" \
  -H 'content-type: application/json' \
  -d '{"model":"gpt-4o","stream":true,"messages":[{"role":"user","content":"hello"}]}'
